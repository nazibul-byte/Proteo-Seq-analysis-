# Proteo-Seq analysis code and data

Scripts and processed data used for snATAC-seq, single-cell proteomics, species-mixing validation, and same-cell protein–chromatin analysis in the Proteo-Seq study.

## Folder guide

| Folder | Scripts and purpose | Required inputs |
| --- | --- | --- |
| `01_ATAC_preprocessing/` | `run_nfcore_atacseq.sh`: aligns ATAC-seq reads using nf-core/atacseq. `bam_to_fragments.sh`: combines per-well BAM files into a barcode-indexed fragments file. | Sequencing FASTQ files and an nf-core sample-design CSV for alignment; per-well BAM files for fragment generation. |
| `02_ATAC_ArchR/` | `archr_core_analysis.R`: creates ArchR Arrow files, performs quality filtering, dimensionality reduction, clustering, and GeneScore analysis. | Indexed `fragments.tsv.gz` and its `.tbi` index. |
| `03_ATAC_figures/` | `MCF7_gene_activity_analysis.R`: MCF7 GeneScore plots and ER/luminal score analysis. `MCF7_ESR1_coverage.R`: ESR1 accessibility track. `PDO_manuscript_analysis.R`: PDO GeneScore plots. | Corresponding QC-filtered MCF7 or PDO ArchR projects generated by the ArchR workflow. |
| `04_species_mixing/` | `species_mix_barcoding_analysis.R`: human–mouse barcode specificity scatter plot and microwell spatial map. | `input_data/device4_human_map.xlsx` and `input_data/device4_mouse_map.xlsx` (included). |
| `05_MCF7_proteomics/` | `BlotSeq_MCF7_MS_analysis_styled.py`: analysis and visualization of MCF7 single-cell LC–MS/MS protein groups. | `AMHE023-report.tsv` (included); `AMHE025-report_blank.tsv` (additional input). Reference comparisons can also use `SPIDR_MCF7_Proteins.xlsx` and `Geiger2012_MCF7_Proteins_Ranked.xlsx`. |
| `06_MCF7_HSP90/` | `analyze_hsp90_2.py`: extracts HSP90 AUC from microwell images. `merge_and_plot_hsp90.py`: combines HSP90 AUC, cell volume, and HSP90AA1 GeneScores for plotting. | For image extraction: `hsp90.tif` and `cell_info.xlsx`. For the plotting script: `hsp90_results.xlsx` and `HSP90AA1_geneScores_proj_d7.xlsx` (included). |
| `07_PDO_proteomics/` | `1_build_lob_workbook.py`: calculates the limit-of-blank-filtered PDO protein table. `pdo_ms_clustering_figures.py`: proteomic clustering, marker plots, and volume comparisons. `si_k3_stability_test_readable.py`: k-means clustering stability across k=2–6. `trimodal_integration_figures.py`: protein, chromatin, and morphology comparisons. `fig2_chromatin_protein.py`: matched GeneScore–protein abundance analysis using `blotseq_io.py`. | Processed input workbooks are included. `1_build_lob_workbook.py` additionally requires the original PDO DIA-NN `report.tsv` to regenerate the processed LoB workbook. |
| `08_variance_analysis/` | `variance_analysis.py`: fits per-protein models and calculates variance allocation for MCF7 and PDO cells, including matched GeneScores. | `inputs/MCF7_SameCell_Multiomics_Dataset(1).xlsx` and `07_PDO_proteomics/BlotSeq_PDO_SameCell_Multiomics_Dataset.xlsx` (included). |

## Software

Python scripts use Python 3 with `numpy`, `pandas`, `scipy`, `matplotlib`, `scikit-learn`, `umap-learn`, `openpyxl`, `xlsxwriter`, `scikit-image`, and `Pillow`. Install these with:

```bash
pip install numpy pandas scipy matplotlib scikit-learn umap-learn openpyxl xlsxwriter scikit-image Pillow
```

The R scripts use R with `ArchR`, `SummarizedExperiment`, `openxlsx`, `dplyr`, `tidyr`, and `ggplot2`, as applicable. ATAC preprocessing uses Nextflow and nf-core/atacseq, together with `samtools`, `bedtools`, `bgzip`, and `tabix` for fragment-file preparation.

## Running the analyses

Run scripts from the repository root unless stated otherwise. The R/ArchR scripts contain configuration paths to edit for the corresponding project or fragment files.

**Species mixing**

```bash
Rscript 04_species_mixing/species_mix_barcoding_analysis.R
```

**MCF7 HSP90**

```bash
cd 06_MCF7_HSP90
python merge_and_plot_hsp90.py
cd ..
```

**PDO proteomics and integration**

```bash
cd 07_PDO_proteomics
python pdo_ms_clustering_figures.py
python si_k3_stability_test_readable.py
python trimodal_integration_figures.py
python fig2_chromatin_protein.py
cd ..
```

**Protein variance analysis**

```bash
python 08_variance_analysis/variance_analysis.py \
  --mcf7 '08_variance_analysis/inputs/MCF7_SameCell_Multiomics_Dataset(1).xlsx' \
  --pdo '07_PDO_proteomics/BlotSeq_PDO_SameCell_Multiomics_Dataset.xlsx' \
  --permutations 1000 \
  --out '08_variance_analysis/results'
```

**ATAC preprocessing**

```bash
bash 01_ATAC_preprocessing/run_nfcore_atacseq.sh design.csv atac_results
# Run bam_to_fragments.sh from the directory containing the indexed per-well BAM files.
```

Additional input filenames are listed in the folder guide above and in the scripts themselves.
